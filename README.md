# Bookafé

Landing page do Bookafé, hamburgueria artesanal fictícia, com cardápio em destaque e botão de pedido pelo WhatsApp. Para usar de verdade, troque `WHATSAPP_NUMBER` no script (hoje um número fictício).

Página única (HTML, CSS e JavaScript no mesmo arquivo). Não precisa instalar nada: baixe o `index.html` e abra com duplo clique no navegador.

Feito em português do Brasil, valores em reais.

## Skills do Claude neste projeto

A pasta `.claude/skills/` traz as 11 skills da [Replica](https://github.com/Jakeschincariol/replica-skill) (licença MIT, em `.claude/skills/REPLICA-LICENSE`), fixadas no commit `77c9436`. O Claude Code carrega essas skills sozinho quando abre este projeto. As mais úteis aqui são `/replica-design`, `/replica-brand` e `/replica-launch`.

Os scripts das skills pedem Python 3.8 ou mais novo. No Windows, troque `python3` por `py` nos comandos.
