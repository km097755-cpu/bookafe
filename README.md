# Bookafé

Landing page do Bookafé, hamburgueria artesanal, com cardápio em destaque e botão de pedido pelo WhatsApp.

**Antes de publicar:** troque `WHATSAPP_NUMBER` no fim do `index.html` pelo número real (DDI + DDD + número, só dígitos, ex.: `5511999998888`). Hoje ele é um número de exemplo e os pedidos não chegam a ninguém.

Página única (HTML, CSS e JavaScript no mesmo arquivo). Não precisa instalar nada: baixe o `index.html` e abra com duplo clique no navegador.

Feito em português do Brasil, valores em reais.
